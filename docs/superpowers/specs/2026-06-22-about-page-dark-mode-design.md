# 关于页与全站暗黑模式设计

## 目标

在现有“期末不挂科”网页系统中增加作者关于页和完整的明暗主题切换。新功能必须延续当前白灰、克制橙色、低阴影的视觉语言，并在桌面端与手机端保持一致。

## 设计依据

- 采用 Linear 的“结构应被感知而非被看见”思路：减少无意义分割线，用背景层级、柔和边框和留白建立结构。
- 暗色主题不做颜色反转或纯黑背景，而是由深灰基础色、低饱和表面色、橙色强调色和适当对比度组成。
- 关于页保持产品内页气质，不做营销型大横幅，也不引入与现有系统无关的复杂动画。

## 主题系统

### 模式

- 支持 `light`、`dark`、`system` 三种主题偏好。
- 首次访问默认使用 `system`，跟随操作系统。
- 用户选择写入 `localStorage`，刷新后继续生效。
- 当选择 `system` 时，操作系统主题变化应实时同步。

### 控件

- 桌面端在侧边栏底部增加紧凑的太阳/月亮切换按钮。
- 手机端在顶部栏增加主题按钮，在“更多”抽屉中显示当前主题文字。
- 控件包含可访问名称，并使用 Lucide 图标。

### 颜色策略

主题通过 CSS 变量统一管理，不在组件中散落独立暗色值。

- 浅色背景：现有暖白灰。
- 暗色页面背景：深灰黑而非纯黑。
- 暗色卡片：比页面背景略亮一级。
- 边框：暗色下使用低对比冷灰，避免卡片边缘发亮。
- 正文：柔和近白；次要文字：中灰。
- 品牌橙色保留，但降低大面积橙色背景的亮度和饱和感。
- 成功、错误、蓝色信息状态分别提供暗色柔和底色。
- 阴影在暗色主题中弱化，主要依靠表面层级和边框。

### 覆盖范围

必须检查并适配：

- 页面、侧栏、手机顶栏、底部导航、抽屉
- 卡片、按钮、徽标、输入框、下拉框、文本域
- 导入区、文件上传区、题目选项、答案解析
- 成功/失败/待评阅状态
- 空状态、错误提示、加载状态
- Recharts 的坐标轴、网格、Tooltip 和文字

## 组件边界

- `ThemeProvider`：读取、保存并应用主题偏好。
- `ThemeToggle`：只负责展示与切换，不直接操作存储。
- `About` 页面：静态作者信息与 QQ 复制状态。
- 主题类型和存储键集中定义，避免页面自行判断主题。

## 错误与降级

- `localStorage` 不可用时仍可在当前会话切换主题。
- `matchMedia` 不可用时默认浅色。
- 剪贴板 API 不可用或复制失败时显示“请手动复制：2284517861”。
- 外链失败不影响页面其他内容。
